Linux System Administrator Project

The foundational track of the 100 Days of DevOps Challenge. A practical, end-to-end infrastructure operations workbook covering 8 phases of production Linux engineering. Each phase includes a comprehensive, step-by-step technical guide published on Medium.

Discover the enterprise backstory behind this capstone project. Learn about SavannahTech Technologies' real-world operational challenges in Nairobi, Kenya, the technical constraints of their scaling applications, and why this hands-on Linux administration architecture was commissioned.

Hands-on Implementations

Phase 01

Server Provisioning & Linux Fundamentals

Establish host identity for ss-app-01, record baseline CPU/RAM metrics, install essential sysadmin utilities, and define standard company directory hierarchies.

Read more
Phase 02

User, Group & Permission Management

Implement departmental access control, configure collaborative project spaces, enforce least-privilege sudo, and manage account lifecycles.

Phase 03

SSH, Networking & Server Hardening

Configure authentication, disable root and password SSH logins safely, conduct socket audits, set up UFW firewall, and deploy Nginx.

Phase 04

Disk, Filesystem & LVM Administration

Decouple app data with LVM Physical Volumes, Volume Groups, and Logical Volumes. Configure persistent UUID mounts and demonstrate live online resizing.

Phase 05

systemd Services & App Deployment

Host an Nginx status dashboard, build a background health daemon, package it as an unprivileged systemd unit, and test automatic restart upon simulated process crashes.

Phase 06

Backup & Disaster Recovery

Automate backups with tar, gzip, and SHA256 checksums, schedule 02:00 AM cron execution, implement 7-day retention pruning, and rehearse emergency restorations.

Phase 07

Monitoring, Log Management & Automation

Write telemetry scripts monitoring CPU, memory, and disks, generate warnings when disk usage exceeds 80%, configure automated log rotation, and profile with vmstat.

Phase 08

Incident Response & Acceptance Test

Troubleshoot 6 live production emergencies (port conflicts, permission denials, 100% full disks, backup failures, DNS drops) and compile Root Cause Analysis reports.
